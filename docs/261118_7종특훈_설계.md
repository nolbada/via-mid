중학교 2학년 기말고사 대비 학생 앱(비타민 영어클리닉)의 "7종 특훈 시리즈" 문항을 만든다.
완성 견본: `/home/claude/work/src/참고_7과_문법특훈_완성본.json` (동아 7과 문법 특훈 15문항). **형식·말투·해설 깊이를 이 견본과 똑같이 맞춘다.** 먼저 이 파일을 끝까지 읽는다.

## 한 특훈 = 15문항 = 3회 × 5문항 (계단식 난이도)
- 1회 개념 확인 (문항 1~5): 원리를 확실히 잡는 수준. 한 문제에 포인트 하나.
- 2회 실전 (6~10): 학교 시험 수준. 두 가지를 섞기, 개수 세기, 본문 문장 그대로 활용.
- 3회 고난도 (11~15): 최종점검 '고득점 모의고사' 수준. 모두 고르기, 본문 변형 밑줄, 한 단어 차이 함정, 맞는 문장도 길고 낯설게.

## 출력: JSON 파일 하나 (문항 15개의 배열)
파일 경로는 맡은 특훈마다 지정된 대로: `/home/claude/work/tk_out/<과>-<종류>.json` (예: `7-VOCAB.json`).
각 문항 객체:
```
{
 "id": "7:TKV-01",            // <과>:TK<종류 약자>-<두자리 번호>. 약자: VOCAB=V DIALOG=D GRAMMAR=G EOBEOP=E ORDER=O INSERT=I CONTENT=C BLANK=B
 "k": "mc",
 "a": "다음 중 ~ 것은?",       // 발문. 1학기 문법을 섞은 문항만 끝에 <span class=\"srt\">1학기 중간 복습</span>
 "p": "지문/제시문 (줄바꿈 \n, 밑줄 <u>..</u>, <보기>는 &lt;보기&gt;)",   // 없으면 생략
 "pk": "p의 한글 해석",          // p가 영어면 반드시 넣는다
 "c": ["보기1","보기2","보기3","보기4","보기5"],   // 보통 5개 (어휘는 4~5개)
 "n": 0,                       // 정답 인덱스(0부터)
 "oc": [ {"ko":"보기의 한글 뜻(없으면 \"\")","y":"이유"} x 보기 수 ],   // 보기가 문장·단어일 때
 "st": [ {"en":"문장/조각","ko":"한글 뜻","ok":1|0|null,"y":"이유", "lb":"(선택) 번호표시"} ],  // 보기가 '2개', 'ⓐ, ⓒ'처럼 진술 묶음일 때 ⓐ~ⓕ 각각. 순서·삽입처럼 맞음/틀림이 아닌 카드는 ok:null
 "stl": "(선택) 카드 묶음 제목. 기본 '문장 풀이'. 순서는 '흐름 정리', 삽입은 '단서 카드' 등",
 "r": {"w":[{"h":"정답 ③ ...", "l":["핵심 해설 1~3줄"],
            "p":{"k":"쉬운 문법"(어휘·내용이면 "기억할 것"),"t":"포스트잇 제목 한 줄","l":["1~2줄"],"e":["예문 영어","예문 한글"]}}]},
 "src": "7"                    // 1학기 문법이면 "1"/"2"
}
```
- oc 또는 st 중 하나는 반드시 있어야 한다(둘 다 있어도 됨). oc 길이 = c 길이.

## 해설(이유 y) 쓰는 법 — 가장 중요
- **원리 + 고친 모양** 순서. 예: "call A B(A를 B라고 부르다)는 5형식이에요. 목적어 A 바로 뒤에 목적격보어 B가 붙어서 사이에 as를 넣지 않아요. → call the festival Fur Rondy"
- 정답 보기에도 "왜 맞는지"를 쓴다.
- 카드 하나당 2~3줄 이내. 장황 금지. 초등 6학년도 알아듣게, "~예요/~해요" 말투.
- 영어가 나오면 한글 뜻을 함께: ko 칸, 또는 괄호 "(친절한)".
- 동사가 활용형으로 나오면 기본형과 뜻을 함께: "took → take(가지고 가다)". (문장 속 모든 동사까지는 아님, 해설에서 짚는 동사만)
- 이모지 금지. 표 금지.

## 종류별 기준
- VOCAB 어휘 특훈: 본문 문장 속 교과서 단어의 유의어(정답) 고르기 + 영영풀이 고르기 + 문맥상 쓰임 등. 보기 품사는 반드시 정답과 같게. 오답은 반의어 또는 품사만 같은 무관어(예: happy → glad 정답, heavy·sad 오답). 보기(c)에는 한글 뜻을 쓰지 않는다(풀기 전에 뜻이 보이면 안 됨) — 뜻은 oc.ko로만. 모든 단어는 기본형으로 묻는다. 2·3회는 다의어, 같은 뜻 고르기, 문맥상 어색한 단어 찾기(본문 변형) 등으로 난도 상승.
- DIALOG 대화문 특훈: 같은 의도의 표현 고르기, 빈칸에 알맞은 응답, 어색한 대화 찾기, 대화 순서. 근거는 교과서 대화문·의사소통 표현(내용정리 플러스, 최종점검 대화 워크시트).
- GRAMMAR 문법 특훈: 그 과 핵심문법 2개 중심 + 1학기 중간 문법(1·2과) 약 30% 섞기. 동아 1과: to부정사 형용사적 용법, make+목적어+형용사 / 2과: 간접의문문, want+목적어+to부정사.
- EOBEOP 어법·어휘 다지기: 본문 문장 위 [A / B] 고르기, (A)(B)(C) 짝, 밑줄 중 틀린 것/개수. 본문 그대로의 문장을 쓰고, 바꾼 곳만 함정.
- ORDER 순서 다지기: 주어진 글 다음 (A)(B)(C) 순서 고르기(5지). 해설 st 카드 = 정답 순서대로 각 덩어리 {en: "(B) 첫 문장 앞부분…", ko: 그 덩어리 한글 요약 한 줄, ok:null, y: 연결 단서 한 줄(예: "this festival이 앞의 축제 이름을 받아요")}. stl "흐름 정리". 해설 l은 한글 기승전결 1~2줄.
- INSERT 삽입 다지기: 주어진 문장이 들어갈 위치 ①~⑤. st 카드 = 정답 자리 앞뒤 문장(ok:null)과 단서(연결어·대명사). stl "단서 카드".
- CONTENT 내용·지칭 특훈: 본문 내용과 일치/불일치, 밑줄 친 it/they/them/this가 가리키는 것, 질문에 대한 알맞은 답. 근거 본문 문장은 영어+한글로 카드에.
- BLANK 빈칸 다지기(8과 전용, 대화문 대신): 본문 문장의 핵심 어구 빈칸 고르기. 해설은 간결하게: 이 부분 내용이 무엇이고 그래서 이 말이 들어감 + 정답 번호·영어·해석, 나머지 보기는 해석 위주.

## 품질 규칙
- 정답은 반드시 하나. 오답이 "애매하게 맞을 수도" 있으면 바꾼다. 문법적으로는 맞지만 뜻이 다른 보기는 발문이 '우리말과 같도록'일 때만.
- 보기끼리 길이·모양을 비슷하게(정답만 튀지 않게). 정답 위치는 ①~⑤에 고르게 흩어지게(15문항 중 같은 번호가 4번을 넘지 않게).
- 중2 수준을 넘는 문법(가목적어, 관계부사 등 미배운 것)을 정답 근거로 쓰지 않는다.
- 다 만든 뒤 스스로 15문항을 처음부터 다시 풀어 보고 정답·이유·한글 뜻을 확인한다.
- 마지막에 `python3 -c "import json;d=json.load(open(PATH));assert len(d)==15"` 로 JSON이 열리는지 확인한다.
